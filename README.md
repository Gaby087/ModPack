# A modpack about cobblemon

Modpack de Cobblemon + Create . Este repo es solo para que **Prism Launcher** instale y actualice el pack solo;
no hace falta tocar nada de aquí.

## Instalar (una sola vez)

1. Instala [Prism Launcher](https://prismlauncher.org/) y entra con tu cuenta de Minecraft.
2. Descarga `Gaby_Pack_Prism.zip` y arrástralo a la ventana de Prism
   (o *Añadir instancia → Importar*).
3. Abre la instancia **Cobblemon**. La primera vez descarga todos los mods (unos minutos);
   después arranca el juego.

## Actualizar

No hay que hacer nada: cada vez que abres la instancia, Prism comprueba si Gaby publicó una versión nueva y baja solo
lo que cambió. Si te sale una ventanita de "packwiz-installer", es eso: espera a que termine.

## Si algo falla

- **Error al descargar**: revisa tu conexión y vuelve a abrir la instancia; se reanuda donde quedó.
- **El juego no arranca tras una actualización**: avisa a Gaby con el archivo `latest.log`
  (en Prism: clic derecho en la instancia → *Carpeta* → `logs`).
- No borres `packwiz-installer-bootstrap.jar` de la carpeta del juego: es lo que hace las actualizaciones.

Los mods se descargan de Modrinth y CurseForge; aquí solo están los enlaces. Los jars propios del pack (gaby_core,
gaby_battleui) están en las *Releases* de este repo.
